# Hobbified

Социална мрежа, в която се запознаваш с хора по общи хобита.

## Функции
- Вход и регистрация
- Профил с хобита (категория, конкретни неща, ниво)
- Начална страница с публикации, снимки, харесвания и коментари
- Приятели и предложения по общи хобита
- Известия
- Мини игри с класации
- Настройки (поверителност, тема, известия, акаунт)
- Админ панел

## Стартиране
Няма нужда от инсталация. Отвори `index.html` в браузъра.
Папките `css` и `js` трябва да са до `index.html`.

Пробни профили:
- `niki.gamer` / `demo123`
- `admin` / `admin123` (админ)

## Структура
```
index.html
css/style.css
js/
  data.js           данни и съхранение (засега localStorage)
  auth.js           вход и регистрация
  ui.js             общи помощни функции за интерфейса
  combo.js          падащи менюта с търсене
  images.js         качване и смаляване на снимки
  feed.js           начална страница и публикации
  profile.js        профил и хобита
  settings.js       настройки
  friends.js        приятели
  admin.js          админ панел
  notifications.js  известия
  sounds.js         звуци
  games.js          мини игри
  app.js            стартиране и навигация
```
